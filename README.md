# Мазагин _"Баня У Палыча"_  
## Проект сделан в рамках курсовой работы по предмету Технологии Программирования  

Проект разделен на 2 части: 'библиотека классов' и 'пользовательский интерфейс'  

### Библиотека классов  

Пользовательские типы получили общий вид, что позволяет использовать их в качестве инструмента в магазине любой тематики, не только в тематике бани  

Классы   
'Client' - тип клиентов  
'Wallet' - объекты-кошельки  
'BankCard' - объекты-карты  
'Bonus' - бонусы  
'Классы Command' - объекты-запросы к Wallet, Cash и Bonus для методов увеличения и уменьшения балансов  
'ClientFacade' - класс, объединяющий функционал всех типов библиотеки и упрощающий взаимодействие с библиотекой  

### Интерфейс

Пользовательский интерфейс представляет их себя набор форм  

Интерфейс   
'Menu' - общее меню  
'Admin' - меню администратора  
'ClientChoosing' - форма выбора пользователя, от чьего лица будет производиться покупка  
'Client' - форма покупки  
'Payment' - оплата собранной в 'Client' корзины  
'AdminClient' - администрирование клиентов в базе данных  
'AdminProduct' - администрирование товаров и услуг
